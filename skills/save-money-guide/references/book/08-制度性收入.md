## 8.1 个税专项附加扣除：每月合法降税

个人所得税的应纳税所得额 = 收入 − 5000元/月（起征点）− 三险一金个人部分−专项附加扣除 − 其他扣除。专项附加扣除的作用，就是合法地把应税收入降下来。现行七项专项附加扣除，外加个人养老金税收优惠，一张表看清：

| 扣除项目 | 扣除标准 | 条件与常见提醒 |
| --- | --- | --- |
| 住房租金 | 直辖市/省会/计划单列市1500元/月；市辖区户籍人口超过100万的城市1100元/月；不超过100万的城市800元/月 | 主要工作城市无自有住房且租房即可填报，不需要发票；与住房贷款利息不能同时享受 |
| 赡养老人 | 独生子女3000元/月；非独生子女分摊，每人不超过1500元/月 | 父母年满60岁；父母有退休金也能扣 |
| 子女教育 | 2000元/月/每个子女 | 子女年满3岁至全日制学历教育阶段；父母可各扣50%，或一方扣100% |
| 3岁以下婴幼儿照护 | 2000元/月/每个婴幼儿 | 0~3岁，满3岁当月转入子女教育 |
| 继续教育 | 学历教育400元/月（同一学历最长48个月）；职业资格3600元/年（取证当年） | 自考、在职研究生、各类职业资格证都能扣 |
| 住房贷款利息 | 1000元/月，最长240个月 | 首套住房贷款；与住房租金不能同时享受 |
| 大病医疗 | 医保目录内自付超过15000元的部分，在80000元限额内据实扣除 | 汇算时凭票据填报；本人、配偶或未成年子女的都可归集 |
| 个人养老金 | 每年12000元税前扣除 | 已开立个人养老金账户；存入即扣，退休领取时按3%单独计税 |

一年下来，填全两项常见扣除（如住房租金+赡养老人），差额可达数百至数千元。操作通常需要10分钟左右：个人所得税App→专项附加扣除填报→选年度→逐项填→选择“通过扣缴义务人申报”（每月预扣时扣）或“年度自行申报”（次年退税）。每年12月确认次年信息，换房、父母满60岁都要记得改。

## 8.2 年度汇算：漏填的可以更正，但要如实、要在期限内

- 时间：每年3月1日—6月30日办理上一年度汇算；
- 在App里做“综合所得年度汇算”，对以前年度漏填的专项附加扣除，可以办理更正申报（通常三年内），多缴的税退到银行卡；
- 应补税额不超过400元的可免申报；能退税的一定要申报——那是你的钱；
- 常见退税来源：专项附加扣除漏填、年中换工作、有多笔收入被重复预扣、公益捐赠未申报。

留存要求：租赁合同、证书、票据等资料留存5年备查，到期或不再需要时自行销毁。专项附加扣除是法定权利，正常填报不必担心——但更正申报须基于真实情况，虚构或扩大扣除条件将被追缴税款、加收滞纳金，并可能影响纳税信用。

## 8.3 公积金：不只是买房用的

五种提取场景

| 场景 | 说明 |
| --- | --- |
| 租房 | 无房且租房即可提；分“无发票”与“有发票+备案”两档（见第一章） |
| 还房贷 | 可按年或按月提取，用于偿还本息 |
| 购房/建造/翻建/大修 | 自住住房相关支出 |
| 重大疾病 | 本人或直系亲属患重病，部分城市支持 |
| 离职/退休销户 | 非本地户籍离职后可按当地条件一次性提取 |

公积金贷款：利率是最大的省钱项公积金贷款利率显著低于商业贷款（近年首套5年以上在2.6%~2.85%区间，以最新公告为准）。同样贷100万、30年，公积金贷款比商业贷款（按3.0%~3.5%）总利息少十几万到二十几万。两个必须注意的坑1. 公司按最低基数缴：很多公司按当地最低工资作为缴存基数，导致你的账户余额少、可贷额度低。入职要问清“公积金基数”和“缴存比例”（5%~12%）——这也是薪酬的一部分。2. 断缴：公积金贷款通常要求连续缴存6~12个月，断缴会重置计算。

公积金是你的钱：个人缴存+单位缴存，全部进你的个人账户。“不缴公积金、多发工资”的offer，等于用12%~24%的隐性收入换现金，要算清楚。

## 8.4 社保与公积金：五险一金各管什么

单位代扣的“五险一金”不是可选项，而是国家规定的强制保障，也是多数人每年最大的一笔“隐形缴费”。各自管什么，一句话说清：

| 项目 | 管什么 | 关键点 |
| --- | --- | --- |
| 养老保险 | 退休后按月领养老金 | 累计缴满15年可领；换城市工作要办转移接续，年限累计 |
| 医疗保险 | 门诊统筹、住院报销、个人账户 | 使用规则见第五章；可开通家庭共济 |
| 失业保险 | 失业保险金 | 缴满1年且非本人意愿离职可领，线上申领（见8.5） |
| 工伤保险 | 工伤医疗、伤残补助 | 个人不缴费；上下班途中非本人主要责任的交通事故也算工伤 |
| 生育保险 | 生育医疗费用+生育津贴 | 已并入医保；男职工也有护理假津贴（各地不同） |
| 住房公积金 | 低息房贷、租房提取 | 单位和个人同缴同存；断缴影响公积金贷款资格 |

对一线城市打工人，断缴的真实代价主要在“资格”两个字：购房、车牌摇号/竞价、落户积分，多数要求连续缴纳社保，断缴可能需重新计算（以当地规则为准）；医保断缴次月起停止统筹报销，重新缴纳有等待期。结论：换工作尽量无缝衔接，宁可自己以灵活就业人员身份续缴，也不要断（在户籍地或就业地社保经办机构/App办理，各地对非本地户籍的政策不同）。

## 8.5 失业保险金与生育津贴

失业保险金：

- 条件：失业前用人单位和本人已缴纳失业保险费满1年+非因本人意愿中断就业（被辞退、合同到期不续签、裁员；主动辞职一般不符合）+已办理失业登记并有求职要求；
- 期限：与缴费年限挂钩（常见缴满1年领3个月，最长24个月）；
- 金额：一线城市通常一千多至两千多元/月；
- 顺带领：领取期间医保由失业保险基金代缴；
- 怎么领：国家社会保险公共服务平台、掌上12333App或当地人社App→“失业保险金申领”。

生育津贴：按单位上年度职工月平均工资计发，产假天数按当地规定；由医保基金支付，通常由单位申领后发放给个人。注意：生育津贴与产假工资“就高不就低”，若津贴低于本人工资，差额应由单位补足。

## 8.6 技能补贴与其他“发钱”的口子

职业技能提升补贴：多数城市对依法参加失业保险并累计缴费一定月数（常见12个月以上）的企业职工，取得职业资格证书或职业技能等级证书后发放补贴：

| 等级 | 常见标准 |
| --- | --- |
| 初级（五级） | 约1000元 |
| 中级（四级） | 约1500元 |
| 高级（三级） | 约2000元 |

证书需在目录内，且一般在发证之日起12个月内申领（各地时限不同），同一职业同一等级只能享受一次。入口：当地人社局官网/App搜“技能提升补贴”。其他常见补贴：

| 项目 | 面向谁 | 备注 |
| --- | --- | --- |
| 高校毕业生就业补贴/求职创业补贴 | 应届及毕业2年内 | 一次性，几千元 |
| 青年人才租房/生活补贴 | 新引进人才（学历/技能门槛） | 按月或一次性，需缴社保或落户 |
| 公租房租金补贴 | 符合条件的住房困难家庭 | 需先取得保障资格 |
| 育儿补贴/一次性生育补贴 | 生育家庭 | 各地政策差异大 |
| 消费券 | 全体居民 | 云闪付、支付宝、本地App发放，定点定时抢 |
| 以旧换新补贴 | 家电、数码、汽车、家装 | 见第六章 |
| 免费“两癌”筛查 | 适龄女性 | 社区卫生服务中心 |

找信息的方法（比任何攻略都有效）：1. 关注「所在区+人社局/住建委/医保局/街道办」公众号——补贴第一批通知都发在这里；2. 打开本地政务App（京通/随申办/粤省事/i深圳），搜“补贴”“申领”；3. 每年3月、9月各查一次“本市人才补贴申报”。

## 8.7 存钱结构：省下的钱要有地方去

省钱不是目的，把省下的钱变成不动的钱才是。

免责声明：以下账户结构仅为常识示意，绝对不构成投资建议。

| 账户 | 目标金额 | 工具 | 规则 |
| --- | --- | --- | --- |
| 日常 | 1个月开支 | 活期/货基 | 房租、吃饭、交通 |
| 应急 | 3~6个月开支 | 货币基金、短期存款 | 只用于失业、生病、意外。这是你在一线城市敢辞职的底气 |
| 长期 | 无上限 | 指数基金定投、国债、个人养老金账户 | 按个人长期规划 |

两个要避开的坑：1. 信用卡分期/最低还款：手续费折算年化常在13%~18%，能全额还就全额还；2. 消费贷“低息”话术：“日息万五”=年化18.25%；“月费率0.6%”≈年化13%。只看年化，不看日息/月费率。
