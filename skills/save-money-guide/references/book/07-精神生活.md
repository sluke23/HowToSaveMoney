一线城市的真相是：很多优质资源是免费的，不少高价娱乐性价比并不高。一张150元的电影票看两小时；一张0元的图书馆卡，可以借一年书、上自习、听讲座、用数据库。

<a id="s7-1"></a>

## 7.1 图书馆：性价比很高的会员卡

凭身份证办证（多数城市已免押金），免费能做：

| 功能 | 说明 |
| --- | --- |
| 借书 | 一次5~20册，借期30~60天，可续借 |
| 自习 | 免费自习区（考试季需抢座，部分城市可线上预约） |
| 电子资源 | 馆内/远程访问数据库、电子书、期刊 |
| 讲座、展览、放映 | 公共文化活动，质量常高于商业活动 |
| 亲子空间 | 免费绘本馆、故事会 |

进阶用法：

- 区级图书馆、街道分馆往往人少、离家近、新书更新快；
- 城市书房/24小时自助图书馆刷身份证就能进，是免费的深夜自习室；
- 通借通还：同一城市内各馆的书可以就近还，很多城市已实现全市通借通还。免费学术资源：国家哲学社会科学文献中心（免费注册，人文社科期刊论文可下载）；各公共图书馆采购的数据库，凭读者卡可远程访问。

## 7.2 博物馆与公园：免费是常态

博物馆：绝大多数省市级博物馆、美术馆免费开放（需提前在公众号/小程序预约，热门馆提前3~7天放票）；中国国家博物馆免费，需预约。特展通常单独收费，但常设展已足够看很多次。每年5月18日国际博物馆日、各地“文化和自然遗产日”，大量场馆有免费或半价活动。公园：一线城市的公园体系是真正的公共福利。

| 城市 | 免费/低价资源 |
| --- | --- |
| 北京 | 奥林匹克森林公园、温榆河公园、各类郊野公园免费；市属公园门票仅2~10元，公园年票约百元级，全年无限次进多家市属公园，去3次即回本 |
| 上海 | 黄浦江滨江步道、世纪公园（部分时段免费）、共青森林公园、遍布全市的市民健身步道 |
| 广州 | 越秀公园、天河公园、海珠湿地部分区域免费；白云山门票极低，年票更便宜 |
| 深 | 深圳湾公园、莲花山、大沙河生态长廊、塘朗山——深圳的公园基本全免费 |
| 圳 |  |

怎么找：搜“城市名+博物馆免费开放名单”，或关注本地文旅局公众号（比商业平台更新更全）。

## 7.3 电影与演出：同一张票，差价三倍

| 方式 | 价格 | 说明 |
| --- | --- | --- |
| 周五晚黄金场IMAX | 80~150元 | 最贵 |
| 周二半价日/会员日 | 30~50元 | 多数影院有固定半价日 |
| 早场（10点前） | 25~45元 | 人少、便宜 |
| 影院自有App/小程序 | 比第三方低5~15元 | 第三方“服务费”常3~6元/张 |
| 银行信用卡观影权益 | 9.9~29元 | 有名额限制，需抢 |

买票顺序：猫眼/淘票票查场次→去影院自己的公众号下单（通常最便宜）→或用银行App的观影权益。别买影院里的爆米花套餐（毛利很高），门口便利店买好带进去。演出：大麦、秀动看信息，重点找“学生票”“公益场”“彩排场”（常为正常票的1/3）；livehouse工作日场比周末便宜一半，人还少。

- [淘票票](https://www.taopiaopiao.com)
- [大麦网](https://www.damai.cn)

## 7.4 学习：把“知识付费”换成“公共资源”

| 需求 | 免费/低价方案 |
| --- | --- |
| 系统学一门课 | 中国大学MOOC（多数课程免费，只有认证证书收费）、国家智慧教育平台 |
| 编程/工具类 | 官方文档+视频平台免费教程+GitHub开源项目 |
| 学术论文 | 国家哲学社会科学文献中心、图书馆数据库 |
| 外语 | 图书馆电子资源、播客、免费公开课 |
| 城市公益课 | 文化馆/群艺馆/工人文化宫的免费公益课（摄影、书法、舞蹈、乐器），名额靠抢 |
| 考证 | 职业技能提升补贴（见第八章），考完还能领钱 |

“市民夜校”——一线城市性价比很高的学习方式以上海为例：上海市民艺术夜校每期开设数百个点位、上千门课程，招收学员数万人，采用500元/12次课的公益性收费；同期首推的“市民日校”设78个点位、238门课程，同样是500元/12次课，分“艺术早课”“午间一小时”“都市午茶”三个时段，18~70岁均可报名。热门课程（壁球、爵士鼓、古琴、射箭、网球）常在数秒内抢空，报名日要提前定闹钟。其他城市的对应渠道：北京各区文化馆、广州文化馆、深圳文化馆/职工服务中心，多为免费或低价公益培训，关注区级文化馆公众号即可。

## 7.5 语言：免费学习路径，先看境内资源

想学英语和小语种的人，可以先通过下面的免费方式进行学习充电，利用好这些免费资源；是否需要付费课程，按自己的目标和进度决定即可。

一、英语：免费资源的四层组合

| 层次 | 工具（全部免费） | 怎么用 |
| --- | --- | --- |
| 系统课 | 国家智慧教育公共服务平台（外语专区）；中国大学MOOC 英语类课程；中国高校外语慕课平台（Umoocs） | 选一门带作业与测验的完整课程，按周跟完，比零散刷短视频扎实 |
| 词汇 | Anki（电脑与网页版免费）；多邻国 Duolingo | 多邻国负责“每天打开”；词汇量靠Anki 自建本行业词牌组，比背词书快一倍 |
| 听力 | 中国国际广播电台（CRI）英语频道；CGTN 官网与播客；高校公开课 | 精听用 3~5 分钟短材料，逐句听写；泛听用长播客在通勤时听 |
| 口语 | 图书馆外语角；高校英语社团公开活动；语言交换 App（HelloTalk、Tandem 基础功能免费） | 语言交换＝你教中文、对方陪你练英文，成本为零；每周固定一次，比报班有效 |
| 阅读 | 图书馆采购的英文原版书与有声书数据库；公版电子书库 | 办一张免费读者证，馆藏数据库远程可用，相当于白拿数千元的课程会员 |

四城公共图书馆是最大的隐藏资源库：广州图书馆、深圳图书馆、上海图书馆、首都图书馆均藏有大量英文原版书与有声书数据库，多数馆还采购了英语课程类数据库——办一张免费读者证全部可用。到各馆官网“数字资源／数据库”页看清单。

二、小语种：境内公开课＋官方考试样题

| 语种 | 免费资源 | 说明 |
| --- | --- | --- |
| 日语 | 中国大学MOOC／Umoocs 日语课程；国家智慧教育平台外语资源 | 零基础到 N3 的语法与词汇课基本齐全；JLPT 备考用官方历年真题 |
| 韩语 | 中国大学MOOC 韩语课程；高校韩语系公开课 | 入门阶段足够；TOPIK 官方样题免费下载 |
| 德语 | 中国大学MOOC 德语课程；图书馆德语学习数据库 | 入门后直接用德语官方等级考试模拟题自测 |
| 法语 | 中国大学MOOC／Umoocs 法语课程；图书馆法语数据库 | 入门后用 DELF 官方样题备考 |
| 西语 | 中国大学MOOC 西语课程；多邻国入门 | 入门后用 DELE 官方样题备考 |
| 通用 | 国家智慧教育公共服务平台；高校公开课平台；Coursera／edX 旁听模式 | 大学正课可免费旁听，涵盖多个语种 |

三、一线城市的免费线下资源

- 图书馆外语角／多语角：上海图书馆、广州图书馆、深圳图书馆、首都图书馆均定期举办免费英语角与外语讲座（各馆官网／公众号“活动”页预约）。这是零成本真人对话环境里最容易获得的一个。
- 高校讲座与公开课：四城高校公开讲座大量对外开放（关注校内讲座类公众号、豆瓣同城）。
- 街道文化馆公益语言班：有的街道文化馆不定期开设公益外语班，多为免费或几十元一期，可关注本地文化馆公众号。
- 共青团“青年夜校”外语课：北京、上海、广州、深圳均有铺开，公益价，见本部分第四节。
- 书店与社区活动：城市大型书店常有免费作者分享与双语活动。
- 语言交换线下局：豆瓣同城、语言交换 App 的线下活动，一线城市密度最高，通常只 AA 一杯咖啡钱。

四、性价比高的线下课程：先公共，后市场

| 渠道 | 价格量级 | 说明 |
| --- | --- | --- |
| 市民夜校／青年夜校 | 约500元／12节 | 上海市民艺术夜校是标杆（含日、韩语等课程，摇号报名）；近年北京、广州、深圳的文化馆／共青团系统“青年夜校”大面积铺开，同为公益价 |
| 文化馆／工人文化宫公益班 | 几十元一期或免费 | 名额少、靠抢，关注本地文化馆公众号 |
| 开放大学／社区学院 | 按学分低价收费 | 系统语言课程，有结业证书 |
| 确需应试班 | 约为市场价的1/3 | 优先级：官方真题（IELTS／JLPT／DELF／DELE 均有免费样题）→ 高校研究生家教（平台约100~150元/时，机构300~500元/时）→ 只补弱项的10节课包，绝不买包年卡 |

一句话总结：初期可以充分利用周围的免费或低价资源学习语言；想要更深入、或有针对性、目的性地学习，可以报适合自己的应试班。

## 7.6 旅行与社交：把钱花在“时间”上

旅行：

| 变量 | 省钱的一侧 | 贵的一侧 |
| --- | --- | --- |
| 时间 | 3—4月、9月、11月 | 春节、五一、暑期、国庆 |
| 目的地 | 淡季城市 | 反季节（冬天三亚、夏天哈尔滨） |
| 住宿 | 青旅单间、民宿周租、城市近郊 | 景区内酒店 |
| 交通 | 夜班火车（省一晚房费）、顺风车 | 黄金周高铁/机票 |
| 门票 | 城市公园年票、博物馆免费、景区联票 | 单点购买 |

请3天年假换1周行程：把年假拼在周中，避开周末住宿溢价（周末房价常比平日高40%~80%），一次旅行省1000~2000元。周边2日游：一线城市2小时高铁圈内有大量低成本目的地（北京—天津/承德/张家口；上海—苏州/嘉兴/湖州；广州—佛山/肇庆/清远；深圳—惠州/东莞/珠海）。

社交

- 把聚餐从餐厅挪到家里：4个人餐厅人均120=480元；在家做4人成本100~150元，体验更好；
- AA制明说，一线城市朋友间默认AA是常态，不必为面子抢单；
- 替代方案：爬山、骑车、逛免费展、在家看电影、桌游（人均40~60元，比酒吧便宜一半）。
