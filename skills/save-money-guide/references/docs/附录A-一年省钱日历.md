# 附录A 一年省钱日历

> 许可：按原文工具性内容的特别规定，本附录采用 CC BY 4.0。

省钱有节律，很多优惠只在特定时点存在。

| 时间 | 该做的事 |
| --- | --- |
| 1月 | 医保新年度起付线重置；如有就医需求，优先选择社区卫生服务中心 |
| 2—3月 | 个税年度汇算开始（3月1日起），补填专项附加扣除，多数人可退税 |
| 3月 | 租房淡季，换房与谈价成功率最高（毕业季6—8月最贵） |
| 4—5月 | 家电以旧换新、消费券集中发放期；公园年票续办 |
| 6月 | 电商大促：只买清单里的东西；大件家电、数码的年度低点之一 |
| 7—8月 | 毕业季，不要在这两个月找房；暑期旅游最贵 |
| 9月 | 开学季教育/数码促销；秋招开始，简历照、正装可买二手；流感疫苗开打 |
| 10月 | 国庆后旅游价格跳水，年假请在这时最划算 |
| 11月 | 双十一：提前一个月加购比价，别当天冲动下单 |
| 12月 | 确认次年医保参保状态，并查询本年度门诊统筹限额的使用情况（国家医保服务平台App可查已用与剩余额度）；如确有慢病复诊、长期处方续方等医嘱内的就医需求，可在年度内合理安排，避免跨年重复自付起付线；不要为了“用掉额度”而做无医学必要的检查——限额是共济基金的最高支付 |
|  | 上限，不是个人可支配的福利；确认次年社保基数调整；确认次年个税扣除信息 |
