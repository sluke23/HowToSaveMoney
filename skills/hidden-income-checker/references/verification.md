# 官方核对与金额口径

作者：毛毛&luke。新增核对方法，CC BY-NC-SA 4.0。本文不预设任何当前补贴额度或开放日期。

## 找到支持本项结论的原文

沿“城市/区＋具体项目名＋办事指南/申领条件/申报通知”查主管部门或政务平台，找到项目办法、当前批次公告和办事指南。搜索摘要、自媒体、广告、培训机构与聚合转载只作线索；优先读发布机关原文。

记录对判断实际有用的内容：

- 项目全称、管理部门、地区及层级、资金性质和适用年度/批次。
- 发布/生效/终止时间与后续调整；当前批次是否仍受理，别把往年通知当长期开放。
- 申请人或单位的条件、年龄及时间计算口径、缴费/证书要求、重复或互斥限制。
- 金额或公式、发放周期、最高限额与实际金额的区别、拨付对象。
- 申报窗口、以什么事件起算、补报或更正渠道、是否需要年度续办。
- 材料、个人/学校/单位谁来申请、官方办理入口及查询日期。

法律依据和实际办事指南结合读。遇到旧办法与新通知、不同层级或不同年度冲突，查后续修订及经办解释，未解决就列明冲突，不自行选金额更高的版本。官方指南未提到的限制不反推“不存在限制”，涉及并行享受、自动核发等关键问题仍要核对。

需要登录才能看时，不要求用户提供登录凭证；让用户自行确认或提供去掉个人信息的关键条文。网页访问受阻时，保留已读证据及尚未核实的字段，给具体咨询问题，不编造已经访问成功的记录。

## 规则、个人条件与办理状态分开

| 维度 | 可用表述 | 意义 |
| --- | --- | --- |
| 公开规则 | 待核实 / 已读适用期间原文 / 资料冲突待确认 | 记录查了什么，不替代个人审批 |
| 个人条件 | 缺关键条件 / 按已给信息初步匹配 / 当前暂不匹配 | 写缺什么或不匹配依据，未提供的信息不能当已满足 |
| 办理情况 | 未查 / 未申报 / 已申报待审 / 待补材料 / 已享受 / 当前窗口已过待查补报 | 已享受需注明自动结算、月度扣除、单位发放或到账等依据 |

仅有原书摘录时，规则一栏保持待核实，候选可以写“值得查”，不要输出“已确认可领”。用户说未申报也要核对是否已自动核发、单位已办或每月已扣除。用户说已获批，则以其自述标注，不伪称助手已核账户。

对时限同时看申请截止、补件截止、待遇覆盖期和补报程序。未知日期不能设为本月底或明年某月；窗口已过的也不直接断言永久失权。提醒可以写成建议或日历草稿，实际创建外部提醒需授权。

## 金额怎么写

以下算例是假设，只演示口径。先写期间、条件、是否已享受，再写可复算金额。

**税款减少**：假设追加一项符合条件的全年扣除 3600 元，扣除前后年度应纳税所得额都在 3% 档，新增减税为 `3600×3%＝108 元`。跨档时算完整前后差额；没有应纳税额时不能保证有同额收益。

**退税与减税不要重复**：假设原本年度应纳税额 900 元、已预缴 1000 元，原应退 100 元；新增扣除使最终税额少 108 元至 792 元，修正后总应退 `1000−792＝208 元`。新增带来的改善是 108 元，总应退是 208 元，不能说“208 元退款再加 108 元减税”。若原来仍应补税，扣除可能只是少补，不一定得到退款。

**账户提取**：已确认可从公积金账户按月提取 1000 元，只在“账户资金”中列对应期间可提取额，不能同时算作补贴 1000 元和房租下降 1000 元。提取金额受余额与现行规则约束，不能凭月工资或房租推算全年都可提。

**保险待遇、工资和报销**：先对齐发放期间、单位是否已垫付、谁接收、是否要补差与已结算金额。生育津贴不与同期产假工资重复累计；已在就医结算中减免的报销不列为待领取现金。失业待遇按核定期间与就业状态变化计算，不能直接乘满 12 个月。

**住房、服务、消费补贴**：用实际替代的支出估算减免，不把公租房市价差、免费住宿挂牌价、优惠券面值当成可提现收入。假设原计划同规格购买价 3000 元，补贴后实付 2700 元、另有必须新增的费用 100 元，则该方案现金少花 `3000−2700−100＝200 元`；没有原购买计划，就不据此声称多赚 200 元。

只有金额、期间、适用条件及是否可并行享受均明确的项目才汇总。重复项目、同一家庭成员的共享上限、月度与一次性、全国与地方叠加规则逐一核对。未知金额写待定，不当零；有互斥的列不同方案，不把各项上限加成年度收入预测。

| 事项 | 机构或入口 | 继续查什么 |

| 税务 | [国家税务总局](https://www.chinatax.gov.cn)；本人在个人所得税 App 查询 | 对应年度专项扣除、汇算、更正程序；必要时咨询 12366 |
| 失业等社保待遇 | [国家社会保险公共服务平台](https://si.12333.gov.cn) | 参保地具体待遇与申报、停领、医保衔接；必要时咨询 12333 |
| 医保与生育 | [国家医保服务平台](https://fuwu.nhsa.gov.cn)及参保地医保部门 | 本人类别、费用或津贴项目、经办对象与材料 |
| 北京政务与公积金 | [北京市政务服务网](https://banshi.beijing.gov.cn)、[北京公积金](https://gjj.beijing.gov.cn) | 选择具体市区事项和适用提取方式 |

| 就业、人才、技能 | [北京人社](https://rsj.beijing.gov.cn)、[上海人社](https://rsj.sh.gov.cn)、[广东人社](https://hrss.gd.gov.cn)、[深圳人社](https://hrss.sz.gov.cn) | 具体市区项目、证书目录、申领窗口和重复享受规则 |

咨询问题尽量具体，例如：“我在【区】、【月份】离职，失业保险记录约【时长】，目前【状态】。请问【项目】应在哪个参保地申请、需要什么离职原因材料、当前申领/补报程序是什么？医保待遇如何衔接？”不要只让用户问“我能领多少钱”。
