# 费用与通勤算法

本文件是基于指南租房比较方法新增的计算说明，作者：毛毛&luke，CC BY-NC-SA 4.0。原书 1.1 的算法仍待核实，不用于本计算。

## 统一口径

所有金额用人民币元。选择同一预计居住期 H（月），每月实际到岗 D（天），单程门到门通勤 T（分钟）。远程办公日不算往返通勤；双职工分别计算后汇总，不能把一个人的分钟数当成全家成本。

- 每月现金支出 M＝房租＋交通月费＋其他居住月费。物业、宽带、服务费、实际水电、取暖年费等按预计住期合理分摊，不重复计算已含在租金的项目。
- 月通勤小时 Q＝2×T×D÷60。
- 预计住期现金成本＝H×M＋新增一次性费用 U。U 可含中介、搬运、安装、过渡住宿、重复租金、已明确的提前解约损失；已花且收不回的历史费用不再加入。跨月费用或租金上涨不能用单一月费近似时，分阶段计算。
- 可退押金 P 单列；首期住房付款＝首期预付月数×房租＋P＋U。这里不含之后发生的交通、水电等账单。U 中已经计入首期租金或押金会重复，应先拆分。
- 用户指定时间价值 V（元/小时）时，月时间折价＝Q×V；住期钱与时间合计＝现金成本＋H×Q×V。这是偏好测算，不是实际现金支出或副业收入。

月费未知不能用零代表已核实无此费用。可先声明“仅比较已知项目，其他暂按双方相同”，并指出未知差额可能改变结论。押金退不回、超期通知、预付租金不可退等分别做情景，不作默认损失或默认全额退还。

## 和基准房源比较

设 A 为当前住房或基准，B 为备选：

- 每月现金净省 S＝M_A−M_B；新增一次性费用 ΔU＝U_B−U_A。
- 预计住期净省＝H×S−ΔU。
- 每月多通勤 ΔQ＝Q_B−Q_A。
- 当 ΔQ＞0 且 S＞0，“少通勤一小时的经常性价格”＝S÷ΔQ。
- 若住期净省≥0，“本住期时间价格临界点”＝(H×S−ΔU)÷(H×ΔQ)。超过此价格才倾向少通勤方案，前提是其余条件可接受；边界值表示打平。
- S＞0 且 ΔU＞0 时，现金回本月数＝ΔU÷S，完整月份向上取整。S≤0 时不能说“迟早靠月租回本”。一次性费用更低但月费更贵的方案可能前期便宜、长期更贵，应看住期总账。

现金与时间均不更高的一方，也仍要检查房屋条件和用户硬约束，不能用分数自动覆盖消防、睡眠、照护等需求。

## 运行内置计算器

Python 3.9+，无第三方依赖。从任何工作目录都可运行；把 `<skill目录>` 换成安装目录，输入输出文件放在用户指定或临时目录。

```bash
python3 "<skill目录>/scripts/compare_rent.py" --input /path/to/options.json
```

输入格式；下列数字均是假设，不是在租报价：

```json
{
  "months": 12,
  "workdays_per_month": 22,
  "plans": [
    {
      "name": "A 现住",
      "rent": 4500,
      "commute_minutes_one_way": 30,
      "transport_monthly": 200,
      "deposit": 4500
    },
    {
      "name": "B 备选",
      "rent": 3500,
      "commute_minutes_one_way": 60,
      "transport_monthly": 300,
      "upfront_cost": 2400,
      "deposit": 3500
    }
  ]
}
```

`months` 为正整数；`workdays_per_month` 可用 21.75 等实际估计，范围 0–31；`plans` 至少两项，第一项是基准。每项必填 `name`、`rent`、`commute_minutes_one_way`、`transport_monthly`；`other_monthly`、`upfront_cost`、`deposit` 缺省为 0，`prepaid_months` 缺省为 1。缺省只适用于明确标示的比较假设。`time_value_per_hour` 是可选的用户时间估价；缺省不生成时间折价总成本。预付月数为正整数，其他数值非负且有限，错误输入会报错，不生成结果。

结果 `plans` 给每项现金、通勤、首期住房付款；`comparisons` 依次与第一项比较。正的 `period_cash_saving` 表示备选在预计住期少花钱；`cash_payback_months` 为连续回本月数，`cash_payback_full_months` 为向上取整的完整月数；`null` 表示按该指标无相应回本或临界点，不等于零。

上例双方其他月费暂按相同且未列。A 每月 4700 元、通勤 22 小时；B 每月 3800 元、通勤 44 小时。B 每月少花 900 元，多通勤 22 小时；不计搬家时，一小时对应 40.91 元。计入 B 的 2400 元新增费用，12 个月净省 8400 元，回本约 2.67 个月（第 3 个完整月），本住期时间价格临界点降为 31.82 元/小时。

如果现住 A，已付的押金不必重新拿出来交：A 的 `initial_housing_cash` 是合同首期口径，不是续住新增付款；报告中另写当前余额、B 首付款及旧押金预计返还时间，不能在旧押金未退前当成可用现金。预付周期跨过预计退租日时，另查剩余租金退款约定。脚本不模拟逐日现金流、资金利息或政策审批，不替用户作综合选择。

脚本的 JSON 结果用于计算核对；给用户展示时把字段转为“每月支出、住期总成本、多花通勤时间”等自然语言，通常金额保留两位小数即可，不倾倒整段 JSON。
