# 完整示例：把方法用于家庭打印

这是编辑示范，所有价格、用量与性能条件均为假设，不是市场报价、真实用户经历或设备推荐。先看成稿如何连接条件、算例和行动，再看编辑说明。

## 成稿

### 家里要不要买打印机：先看三年会印多少页

如果只比较普通 A4 黑白打印、两种方案都满足质量与交付需要，并且附近打印店不需要额外跑一趟，那么低频使用时先按页打印更省。买设备是否值得，主要取决于三年总页数，而不是机器标价看起来便不便宜。

假设新打印机一次支付 900 元，三年不更换，期末残值为零；每页纸、电和耗材合计 0.10 元。外部打印按每页 0.50 元收费，无另收服务费。先演示设备三年无需另付维修、更换耗材已包含在每页费用中的情景，时间与风险另列；这些条件均需用实际报价核对。

| 同一需求下的方案 | 三年现金成本公式 | 每年 1000 页，共 3000 页 | 每年 300 页，共 900 页 |
| --- | --- | --- | --- |
| 买新打印机 | 900＋0.10×总页数 | 1200 元 | 990 元 |
| 外部按页打印 | 0.50×总页数 | 1500 元 | 450 元 |

每年 1000 页时，买设备三年少付 `1500−1200＝300 元`；每年 300 页时，外部打印反而少付 `990−450＝540 元`。购机当下还需要先付 900 元，低频方案不能靠三年总额掩盖这笔首期支出。

求现金成本相同的总页数：`900＋0.10Q＝0.50Q`，得 `Q＝2250 页`。三年正好印 2250 页时两者同为 1125 元；在这个简化情景里，从 2251 页起购机才严格更省。不是“买回来多用就一定赚”。

如果三年额外发生 200 元维修且其他假设不变，等成本点变为 `(900＋200)÷(0.50−0.10)＝2750 页`，从 2751 页起才更省。实际维护尚不清楚时，应先查设备的耗材、保养和保修条件；这 200 元只是情景，不是对维修费用的预测。

时间和便利还会改变选择。如果外部打印要专程往返，记录往返与等待时间；家用设备也要考虑安装、排障和维护。两者时间先分开列，不未经个人估值换算成工资。涉及隐私文件时，还要核对外部处理、留存与删除方式；不能只因单页价低就认定方案可用。

第一步先看近三个月实际打印页数与类型，区分是否有临时考试、项目等非常态需求，再估未来使用量，不能简单把旺季乘十二。然后向门店确认黑白单页、双面计价、起印费与交付时间，向设备方确认购置价、耗材成本边界和保修。记录得到的报价与日期，代入表格重算；在用途和用量不清时，可以先保留按页付费，观察后再决定，不必为跨过回本点刻意多印。

本节计算只来自上述假设，现实报价与维护条件尚未核实。取得实际数据后，若单价、剩余寿命、现有设备状态或服务质量不同，应调整模型；彩色、照片、大幅面等需求不适用这组黑白打印比较。

## 编辑说明

| 成稿中的处理 | 对应纪律 |
| --- | --- |
| 先限定 A4 黑白、质量达标、三年、无额外跑腿 | 需求、期间和成本边界先齐，功能不同不直接拼价格 |
| 给出总页数变量、完整公式与两种用量 | 算例能复算，也能看到结论何时反转 |
| 等成本点与严格更省分开，另列 200 元情景 | 不把相等写成回本后已省，维护不确定时不默认永远为零 |
| 首期现金单列，时间和隐私不硬折钱 | 总成本、支付压力与非金钱约束不混写 |
| 最后给实际页数、询价字段和重算步骤 | 第一步有对象、数据和完成凭据；没有把“理性购买”当行动 |
| 明说全部是假设，无假链接或个人见证 | 计算示范不冒充市场调查，也不硬找权威为虚构价格背书 |

不要把打印例子的“三年”或“每页单价”迁移到所有主题。学习一门技能可能要看起点、目标、练习时间与反馈，不能仅用课时单价衡量学习效果；选择云服务要核对用量、功能、版本与迁移，不能假定相同月费代表相同服务；照护等主题的质量与责任约束可能比成本差额更先决定可行方案。这些是调查问题，不是已核实的具体产品或效果结论。

## 同一句话怎样改得有用

原句：“打印机是家庭省钱神器，买对了每年省几千，闭眼入。”

可改为：“在三年 3000 页、设备 900 元、每页自印 0.10 元、外部 0.50 元且无额外维护等所列假设下，购机三年现金少付 300 元；若总量只有 900 页，则外部打印少付 540 元。先确认真实用量和报价，再决定是否购机。”

这段改写没有靠同义替换“去 AI 味”，而是补了比较周期、计算输入、结论翻转条件和第一步。短文不必照搬完整章节长度，但不能把这些决定性条件删成无条件承诺。
