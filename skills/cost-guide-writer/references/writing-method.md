# 写作体例与迁移方法

## 原书中可迁移的做法

先把本页方法用于新主题；只在需要观察具体段落时读相应原文。方法是从原书及其修订中提炼，不保证原书每处都符合这些要求。

| 做法 | 内置样本 | 迁移后要回答的问题 |
| --- | --- | --- |
| 同时考虑金钱、时间与风险，区分检查和办理 | [0.2 三条原则](guide/book/00-这本书怎么用.md#s0-2)、[0.3 怎么读](guide/book/00-这本书怎么用.md#s0-3) | 读者真正要保住什么？今天能完成哪一步，结果要什么时候验证？ |
| 小项降价可能被关联收费抵消 | [4.2 宽带](guide/book/04-水电气网与话费.md#s4-2) | 这项选择改变了哪些绑定条件，完整周期的账会怎样变？ |
| 引入一次性切换成本与使用期限 | [1.5 续租](guide/book/01-住处.md#s1-5) | 预计用多久，净差额何时回本，时间与质量是否还能接受？ |
| 收益只对实际需要、可实现且不重叠的部分计算 | [4.5 记账](guide/book/04-水电气网与话费.md#s4-5)、[6.6 会员](guide/book/06-购物.md#s6-6) | 相对哪个基线省了什么，是否为了“省”新增支出？ |
| 将权利/资格、办理与实际结果分开 | [8.2 汇算](guide/book/08-制度性收入.md#s8-2) | 有项目是否等于适用，提交是否等于获批，限额是否等于到账？ |
| 明确经验阈值与数学示例的边界 | [13.2 预付](guide/book/13-防守.md#s13-2)、[13.3 借贷](guide/book/13-防守.md#s13-3) | 哪个数是假设、哪个是规则？情景变化时哪一步必须重算？ |
| 将疑点与修订保留下来 | [待核实清单](guide/docs/待核实清单.md)、[修订记录](guide/docs/2026-11-16-读者反馈修订.md)、[贡献方法](guide/CONTRIBUTING.md) | 哪些结论可用、哪些尚缺依据，后来改了哪里？ |

不要迁移原书的 1.1 待核实公式、固定月份行情、一般化法律断言或绝对化修辞。新主题有自己的事实来源，原书只支持写作方法的来历。

## 新主题先写一份短说明

用已知信息填写即可；不是要求用户回答全部问题的问卷：

- **读者与决定**：谁在什么场景下，要决定买不买、选哪种、如何使用或如何退出？
- **比较边界**：要达到什么效果，最低质量/安全条件是什么，在哪个地区或版本、看多久、用多少？
- **已知与缺口**：已有报价、账单、规则、数据和经验是什么；哪些缺口会影响结论？
- **交付范围**：一篇、一章、整本或旧稿修订；篇幅、媒介、语气、署名与既有格式要求是什么？

缺少会改变主要比较的条件时，先问或列条件分支。用户只要目录就完成目录；要正文时可以在明确假设下成稿，将需要核实的现实事项另列，不反复索要研究计划确认。

## 长稿如何搭目录

用下面的逻辑选模块，按主题合并、删减和重排：

1. **这份说明书怎么用**：读者、范围、目前能支持的结论、从哪个决定开始。
2. **成本从哪里来**：需求如何产生支出，哪些是固定、按量、首次、绑定、维护或退出费用，时间和非金钱约束是什么。
3. **关键选择**：每章解决一个实际决定，列可行方案和改变结论的条件。
4. **开始与长期使用**：准备、核对、实施、确认结果；持续维护或复查节点。
5. **退出与损失控制**：适用时写取消、更换、残值、材料与风险；不为每个主题硬造法律章节。
6. **可复用工具与依据**：有用才附比较表、询价清单、时间线、计算说明和核查记录。

目录标题描述问题或动作，不用“全面解析、核心秘诀、终极攻略”等词填满章节。地区差异确实改变资格或选择时再分地区；没有差异就不造四城专章。输出为现有项目文件时沿用其编号和路径，不未经请求搭建一整套发布工程。

## 单章怎么串起来

一章通常沿“决定 → 条件与口径 → 方案比较 → 算例及变化边界 → 行动与依据”展开。短稿可合并成几段，长稿用小标题与简表。每段推进一个判断，不重复总论。

可按以下骨架起草，方括号是需要用真实内容替换的写作位；用户要求成稿时不交付未填空的骨架：

```text
# [读者问题：这章帮助决定什么]

[先给条件化结论；说明适用对象、周期与需求]

[拆主要成本，说明没有计入或尚未确定的项目]
[必要时给同口径方案表，质量与适用限制分开]

[已知数据/假设数据、公式与结果；哪些输入改变时要重算]

[第一步找谁/看什么/问什么；确认费用、资格或结果后再做什么]
[完成凭据、复核节点及需要停止或改变方案的条件]

[能支持关键结论的来源与日期；未知项及如何核对]
```

有重要数字时给复算路径，不必每章发明一个公式；无法量化的主题用事实约束、明确标准和情景选择。比较表应便于读者选方案，细碎条件接在表后，不铺十几列让表格变成资料堆。

## 改稿如何下手

先找最会误导决定的句子：对象不明、口径不齐、因果跳跃、旧价格冒充现价、没有证据的普遍判断，以及“节省 X 元”却漏掉新成本。保留可用事实，补一组明确条件和复算，再改结论。

若缺关键来源，选择收窄事实陈述、改为假设例或标注待核实；不能把待核实的金额换成同样无依据的区间。评论与亲历可发现问题，不能自动成为规则依据。改动数值、范围或结论时说明影响；纯文字润色无需逐句列修改账。

## 语言靠信息变具体

| 原句问题 | 可用的改法 |
| --- | --- |
| “一年省下大几千，半小时轻松搞定” | 写账单期间、实际可取消项目和预计少付的下一笔金额；把整理耗时与等待处理分开 |
| “贵的一定更耐用” | 写规格、保修、预期使用、维修与残值；没有对比证据就不给绝对寿命结论 |
| “这笔钱人人都能领” | 写地区、身份、资格、已享受情况和窗口；未核实时第一步是找适用指南 |
| “按需选择，理性消费” | 写出会改变选择的具体阈值或限制，以及下一步需要取得的数据 |

用熟悉的词和具体动词，不训诫读者、不用消费多少衡量自律。避免每节都用“三大原则”“三条铁律”包装，条件和代价要靠事实支撑。
