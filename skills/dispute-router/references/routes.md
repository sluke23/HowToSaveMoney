# 渠道与判断边界

先判断当事人关系与用户目标，再选主渠道。下表用于形成初步路线；正式提交前按 [官方核对方法](official-verification.md) 确认具体机构与受理条件。指南是生活经验来源，不能代替现行法律与程序规定。

## 不同渠道解决什么

| 渠道 | 主要作用 | 不能直接推导的结果 |
| --- | --- | --- |
| 对方、平台客服、调解组织 | 核对事实、按约处理或促成自愿协议 | 客服承诺不等于已履行；调解不当然产生可直接执行的文书 |
| 行政投诉 | 在部门职责内处理权益争议，可能组织调解 | 不等于裁判私法债务或保证退款到账 |
| 举报 | 提供涉嫌违法线索，由有权机关核查 | 处罚不等于赔偿；投诉与举报可有不同处理程序 |
| 12345 | 非紧急政务咨询、按职责转办 | 不代替诉讼、仲裁、复议，不是通用判退款渠道 |
| 劳动人事争议仲裁 | 依法处理属于受理范围的劳动人事争议 | 不涵盖所有个人劳务欠款，不与民商事仲裁混用 |
| 民商事仲裁或法院 | 按适用约定与法定程序作出裁判 | 有仲裁字样不等于条款必然有效；小额纠纷不等于自动适用小额诉讼 |
| 执行程序 | 对符合条件的生效法律文书申请强制履行 | 取得裁判不等于对方有财产可供执行 |

## 按关系选择路线

| 场景与关键区分 | 主渠道如何选 | 何时改变路线、特别保留什么 |
| --- | --- | --- |
| 私人房东扣押金、维修费或退租争议 | 无明显紧急因素且未沟通过，可先向合同相对方书面列明退还金额和理由；已拒绝或失联，则转向当地调解或核对民事争议解决程序 | 查出租/代理身份、合同争议条款及房屋所在地等管辖因素。12345 可问当地租赁主管部门职责；不能一律转 12315。保留租约、押金、入住与退租交接、扣款理由和维修明细 |
| 中介、租赁公司收费或服务争议 | 分开中介服务、租赁合同和涉嫌违规收费；按当地分工核对住房租赁主管部门或市场监管渠道 | 商业主体参与也不能直接推出所有问题都归 12315。签约方、收款方、代理权限要逐一对应，避免只找门店员工 |
| 商品、服务、预付卡退款 | 找实际经营者；通过平台购买且仍有争议处理窗口，可先用平台通道。协商无效或停业时，核对 12315/属地及行业主管部门受理范围 | 查签约经营主体、履约门店、已消费与赠额规则。加盟、换老板、品牌相同不能证明总部或新店必然承担旧债；关门也不能直接认定诈骗 |
| 私人二手交易 | 先保留平台订单和描述，使用平台争议处理；无法解决时核对合同争议解决方式 | 核实是偶发出售闲置还是实际经营，不把个人买卖一概按消费者投诉办理；退货权、欺诈赔偿不能直接套用 |
| 在职/离职欠薪、解除或劳动关系争议 | 事实清楚的工资拖欠，可核对当地劳动保障监察职责；需要确认劳动关系、争议工资或解除待遇等，则核对有管辖权的劳动人事争议仲裁机构 | 没签劳动合同不能直接否定劳动关系。劳动争议通常有仲裁前置，但具体请求、例外和后续救济要另核对；监察与仲裁不是必须先后走完的阶梯 |
| 兼职、外包、接单服务费未付 | 根据实际用工管理、报酬约定、履行情况判断是劳动关系还是民事劳务/服务合同；不只看合同标题 | 管理、考勤、工作指令、交付、验收和结算材料有助分流。无法判断时先向当地劳动争议咨询渠道核对关系，不直接给出唯一仲裁结论 |
| 社保、公积金、医保经办争议 | 按险种、事项及参保地向相应征收/经办或主管部门核对；公积金另找公积金管理中心 | 补缴、待遇核定、单位赔偿和对行政处理不服可能属于不同程序。不要一概让劳动仲裁解决，也不能用重复热线投诉代替法定救济 |
| 订阅、自动扣费、通信账单 | 先核对扣款方、购买渠道、授权和账单，向官方商户/平台要求说明；通信服务先向运营商申诉 | 退订未来扣费与退回已扣费用分开；卸载 App 不等于取消合同。升级电信用户申诉时查通信管理部门现行前置条件与入口，不凭旧热线猜流程 |
| 不认识的扣款、疑似盗刷或诈骗 | 正在发生时先联系银行/支付机构官方渠道核查、控制继续损失；涉嫌犯罪向公安机关报案 | 按时间留交易流水、交易号、对方账号/链接、接触经过；不要为集齐证据继续转钱。银行核查、报案不保证止付成功或全额赔付 |
| 借贷、银行保险证券服务争议 | 先确认持牌主体、产品与实际收费/催收方，向机构官方投诉；再按业务核对相应金融监管或争议解决渠道 | 不把民间借款、银行、保险、证券和助贷平台混为一个主管部门。IRR、逾期或骚扰事实分别核对，不能凭年化数字认定违法或建议停还 |

一般生活纠纷优先读指南 [13.6](guide/book/13-防守.md#s13-6)；具体事实再读 1.3–1.4、4.1–4.2/4.4、6.2、8.4 或 13.1–13.5，入口见 [目录](guide/目录.md)。招聘或投资场景中的费用、兼职方式和收益话术只是风险线索，不是对特定人的定罪依据。

## 不照搬原文的简化说法

- 原文的“协商→投诉→诉讼/仲裁”是提示，不是所有案件的法定前置顺序。已有拒绝、失联、紧急风险或期限时，按实际情况直接核对下一程序。
- 看房前收费、低价、停业或先收费用需要核查具体约定和行为；不能仅凭一个信号宣布“就是诈骗”。
- “口头承诺不算数”“文字高于电话”不是通用证据规则；口头约定可能需要其他证据印证，合同、付款、聊天、录音须结合全文判断。
- 不许诺无条件七天退款、退一赔三、十倍赔偿、固定诉讼费或一定能在线立案；须查交易类型、请求依据和现行条件。
- 12348/[中国法律服务网](https://www.12348.gov.cn) 可用于法律咨询及查找服务；法律援助是否可获得需核对事项范围与资格，不保证免费代理。

## 需要正式法律程序时

已有裁判、仲裁裁决、支付令或行政决定，先确认文书性质、作出/送达日期、救济方式与期限。需要核对管辖时使用履行地、对方住所、房屋所在地、仲裁条款等已知事实，不为未知地点编造具体法院。

不要把所有“欠钱不多”都导向小额诉讼，也不建议在不清楚请求范围时签放弃权利的和解、撤回申请或出具结清证明。可以整理待确认条款、申请材料和金额组成；受理、保全、费用、送达、期限及执行条件按适用程序另核。
