# 证据与行动模板

回答“留到什么程度”要同时处理材料是否够用和保存多久。按当前目标收集，缺材料时指出缺哪个事实、怎么合法补；不能让用户先集齐整套文件才能求助或报警。

## 用事实决定材料

| 要说明的事实 | 常见材料 | 核对点 |
| --- | --- | --- |
| 与谁形成了什么关系 | 合同、订单、店名与经营主体、对方账号、工作安排 | 签约方、收款方、服务方不一致时分别记，不能只写品牌名或员工昵称 |
| 约定是什么 | 合同全页、商品描述、相关宣传、报价/工资约定、完整聊天 | 保留版本、时间及上下文；有口头约定时记录过程并找相互印证的材料，不虚构补签 |
| 我付了钱或履行了义务 | 原始账单、订单号、转账回单、工作/交付记录 | 金额、日期、收款人、用途；未签合同的劳动争议可用管理、考勤、工作指令和工资记录等辅助说明 |
| 对方哪里没有履行 | 交接/验收、瑕疵照片、停业公告、扣费账单、欠薪月份与计算 | 区分亲历事实、对方说法和推测；不开门的照片不能独自证明永久停业或诈骗 |
| 我要求什么、对方如何回复 | 催告、客服工单、送达/接收记录、退款回复、已退金额 | 写清请求、金额组成和时间，不把拟要求的金额写成已经被确认的债务 |
| 主张的实际损失或余额 | 充值/消费/退款明细、修理报价/票据、工资应付与已付表 | 押金、未消费本金、赠额、利息、赔偿分开；承认未知项，不把赠额全当现金本金 |

初次咨询通常先带“时间线＋对方线索＋主要约定/付款＋明确诉求”，问清受理方向。正式投诉或申请按该渠道材料要求补齐；诉讼、仲裁等还可能涉及主体信息、请求依据、送达和证据形式，不能用通用模板保证达到受理或证明标准。

劳动争议中，与请求有关的证据由单位掌握管理的，记下材料名称、涉及期间、保管主体与已知线索，依法请求其提供；不能要求个人私自登录单位系统或补齐本就无法取得的全部内部资料。是否承担举证责任及不提供的后果，按适用规则和机构判断。

## 原件、备份与保留终点

- 保留纸质原件、原始电子文件、原设备/账号中能核验的记录及必要上下文。聊天截图、录屏或导出文件作为工作副本，尽量带账号标识、日期和相关前后文；不要只存一张裁切图后删除原始聊天。
- 为材料编号并记来源、取得时间、对应事实；照片/视频保留原文件和元数据，事后在视频里补说日期不能证明拍摄日期。编辑标注、脱敏、压缩另存副本，不覆盖原件。必要时做一份受控备份。
- 不要求长期无差别录音录像，不安装偷拍设备、不进入他人私密空间、不盗取账号。录音能否使用要结合取得方式、内容和具体程序核对，不能因“未告知”就一律判定可用或不可用。
- 只向需要处理该争议的人或渠道提交必要材料，按接收要求脱敏或出示完整原件。不要在社交平台公开证件、电话、住址，或用威胁曝光、虚假陈述迫使退款。
- **不要在客服点“结案”、第一次提交或拿到裁判时就删原件。** 至少覆盖争议解决、约定履行及可能需要的救济/执行阶段；是否已能清理，结合和解履行、适用期限及其他法定留存义务确认。期满后清理无关副本、限制访问；无统一适用于所有纠纷的“留满 X 天就够”。
- 大额、真实性争议或平台内容可能灭失时，向适用机构/法律服务核对证据保全、公证等必要性与成本；不把付费公证当作每个普通投诉的必需品。

## 给对方的首条书面请求

适用于没有紧急危险、无需避免接触对方，且沟通仍有意义的情形。用户已经发过同类请求时，不机械重发。

```text
关于[合同/订单/房屋/工资期间]：
我于[日期]与[主体]约定[事项]，已[付款/履行情况]。
目前[具体问题及日期]，依据[实际条款/已核实依据，未知则不填]，
请求[具体处理及金额组成]；如对金额或责任有异议，请说明理由并提供明细。
相关材料为[编号及简述]。请于[建议日期]前回复[处理方案/核对结果]。
```

建议回复日期是沟通安排，不是自行设定的法定期限，也不能据此断言“逾期视为认可”。是否继续联系取决于人身风险、既有答复和程序期限。

## 给平台或受理机构的事实说明

```text
事项发生在[城市/地点]，相对方为[已知名称与身份线索]。
[日期]约定[事项]，我已支付/履行[内容]。
争议是[具体事实]，目前尚未解决[金额或事项]。
我于[日期]向[主体/渠道]提出[请求]，得到[回复/工单]。
希望[具体请求]；如不属于贵方职责，请说明原因及有权处理渠道。
附件[证据编号与对应事实]。尚待核实[缺口]。
```

投诉中的民事诉求与举报的涉嫌违法线索分开写，不夸大、不伪造罪名。正式表单如要求真实身份或联系方式，由用户通过核实过的官方入口填写；不需要把未脱敏资料先交给 AI。

## 留下程序记录

记提交日期、渠道、请求、附件版本、工单/受理编号、受理或不受理答复、补正要求和下次节点。没有回音时按该渠道规则查询，明确拒绝时根据理由换路径或补关键材料；不鼓励重复无差别投诉。

投诉、报警或自行发消息是否影响诉讼/仲裁时效，取决于请求、行为与具体规则，不能自动认定“我投诉过就不会过期”。已知截止日期单独列，来源、起算事实不清时立即核对；不要虚构统一期限。
