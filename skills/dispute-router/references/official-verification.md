# 官方核对方法与资料范围

内置正文是经验与问题线索，不是所有法律、期限和办理条件均已核实的证明。渠道建议与现行程序分别核对；离线可以做事实分诊和草稿，不能声称已查到今天的受理规则。

## 提交前核对

优先从事发地/履行地官方政务服务、主管部门或法院、仲裁机构公布的办事指南找入口；全国平台可作为起点。核对主管机关、事项名称、地域、适用对象、是否生效、有无替代文件、受理/前置条件、材料、费用和期限。指南涉及的普通投诉不自动等于行政复议、行政诉讼等法定救济。

常见原文包括消费者权益保护及投诉举报规则、劳动争议调解仲裁规则、民事程序与电子数据规定，以及当地住房租赁、预付行业、通信或金融服务的规定。只引用实际读到并适用的内容，不用搜索摘要、新闻评论或客服经验当法律原文。

每个会影响行动的关键结论记录：**机构与文件/事项名、条款或办事要求、官方链接、发布日期/生效信息、实际核对日期、适用与未核实边界**。有期限时同时记录起算事实和例外，无法确定就向对应机构或法律服务核对，不先给一个看似精确的最后日期。

## 按问题查找的官方起点

以下是查找入口，**入口列出不等于其中所有现行条款已经核实**，也不能将首页当作某项具体权利的依据。

| 问题 | 官方起点 | 要进一步确认 |
| --- | --- | --- |
| 经营者消费纠纷、涉嫌市场监管违法 | [全国 12315 平台](https://www.12315.cn) 与属地市场监管/行业主管部门 | 经营者与消费关系、地域与行业职责、投诉和举报各自条件 |
| 劳动关系、欠薪、劳动争议 | [人力资源和社会保障部](https://www.mohrss.gov.cn) 及当地人社、劳动监察、仲裁机构 | 请求性质、劳动关系与管辖、仲裁前置及例外、时效和材料 |
| 私人租房合同、中介与经营租赁 | 当地住房租赁主管部门、政务服务网；[中国法律服务网](https://www.12348.gov.cn) | 行政监管与民事争议的边界，争议条款、管辖、调解或法律服务 |
| 社保、医保、公积金事项 | 当地人社、[国家医保局](https://www.nhsa.gov.cn) 及本地医保、公积金管理中心 | 经办/征收职责、是否行政决定、待遇请求与单位赔偿的分别处理 |
| 电信用户申诉 | [工业和信息化部](https://www.miit.gov.cn)、当地通信管理局 | 对运营商先行投诉要求、申诉期限、实际入口与材料 |
| 银行保险、证券或其他金融服务 | [国家金融监督管理总局](https://www.nfra.gov.cn)、[中国证监会](https://www.csrc.gov.cn)、[中国人民银行](https://www.pbc.gov.cn) 及对应属地机构 | 实际持牌主体、产品与具体监管分工，官方投诉和争议解决方式 |

接到陌生“维权客服”“退款专员”时，回到原平台、账单或官方公开渠道独立核实。不要通过对方提供的链接上传证件、开启屏幕共享或支付追款费。
