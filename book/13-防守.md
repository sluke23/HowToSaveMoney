## 13.1 租房陷阱：三类最常见

①押金不退套路：退租时以“墙面污渍”“家电损耗”“未提前30天通知”为由扣钱，甚至失联。预防（在交钱之前做）：

- 合同写明“押金X元，验收合格后X个工作日内退还”；
- 入住当天全程录像：墙面、地板、家电、家具、水表电表读数，视频里口述日期；
- 退租时同样录像，并让房东/中介在交接单上签字或微信文字确认“已验收、无异议”。

应对顺序：书面催告→告知将投诉→12345/街道租赁管理所→人民法院小额诉讼（诉讼费几十元，可线上立案）。

②二房东跑路与租金贷识别信号（出现任一条立刻停）：

- 让你签两份合同：一份租赁合同、一份“分期服务协议/贷款合同”；
- 收款方是金融公司/保理公司，不是房东或中介；
- 大力推销“年付8折”“押一付十二送一个月”；
- 拿不出与原房东的委托出租授权书。铁律：不做租金贷，不年付给非房东主体。

③看房费/诚意金/房源锁定费 看房前收任何费用，基本可认定为骗局或违规收费。

## 13.2 预付卡：健身房、美发、教培、摄影

套路：充值3000送3000，几个月后门店关门或换老板，余额作废。三条自保规则：1. 单店预付不超过1000元，且不超过你一个季度能消费完的金额；2. 只选连锁、且门店经营3年以上的（新开业大促充值=最高风险）；3. 合同写明“未消费余额可退”，保留合同与付款凭证（拍照存云端）。

法规支撑：多地已出台单用途预付卡管理办法，对备案、资金存管、冷静期有要求。纠纷处理：商务部门（预付卡主管）+市场监管12315投诉；涉嫌合同诈骗的向公安机关报案。红线话术：“充值送股权”“充值可分红”“充值返现”——本质上可能构成非法集资，不要碰。

## 13.3 借贷：把“日息”换成“年化”

话术vs真相：

| 话术 | 真实年化 |
| --- | --- |
| 日息万五 | 18.25% |
| 月费率0.6%（等额本息） | 约13% |
| 信用卡最低还款 | 约18% |

换算公式：真实年化 ≈ 月费率 × 22（等额本息分期近似）；日息万分之五 ×365= 18.25%。

- 任何“先交钱/先贷款才能开始”的培训、求职、医美，一律拒绝；
- 只看合同上的年化利率（APR/IRR）；
- 信用卡能全额还就全额还。

两个骗局：

- “征信修复”：不存在。征信异议只能通过中国人民银行征信中心免费提出，任何收费“修复”“洗白”都是骗局；
- “代缴社保/挂靠参保”：违法。一旦认定虚构劳动关系，社保记录可能被撤销，影响落户、购房资格，甚至涉及骗保责任。无单位时正确做法是以灵活就业人员身份参保。

## 13.4 求职与副业：四种会让你“倒贴”的工作

| 陷阱 | 识别信号 | 应对 |
| --- | --- | --- |
| 收费内推/付费实习 | 交“内推费”“实习押金” | “培训费”正规企业招聘从不收费，直接放弃并举报 |
| 兼职刷单/点赞返利 | “先垫付、后返现”，前几单真返 | 属诈骗，且刷单本身违法，立即停止并报警 |
| 高薪日结（无门槛） | 要求下载陌生App、加私人微信、帮忙转账“跑分” | 涉嫌“帮信罪”，会被追刑责 |
| 传销式副业 | 拉人头、交加盟费、层级返利 | 直接远离 |

## 13.5 消费与投资：守住两条线

消费端：

| 陷阱 | 说明 | 应对 |
| --- | --- | --- |
| 先涨后降 | 大促前拉高标价 | 查6个月历史价 |
| 低价钓鱼 | 低于市场价50%以上 | 只在平台内交易 |
| 假客服退款 | 让你开屏幕共享、下载App | 只在官方App内确认，绝不屏幕共享 |

投资端（红线）：

- 承诺“保本高收益”——资管新规后任何理财产品都不得承诺保本保收益，承诺的即违规或诈骗；
- 收益率显著高于市场且号称“无风险”；
- “内部消息”“稳赚群”——杀猪盘标准剧本：小额提现成功→加大投入→无法提现；
- 虚拟货币、“原始股”“养老项目”——非法集资高发区；
- 熟人推荐、拉人头返利——传销特征。

最基本的动作之一：投资前在证监会、国家金融监督管理总局官网查机构与产品资质。不确定就不投。

## 13.6 维权工具箱，与“省出问题”的反向清单

| 场景 | 渠道 |
| --- | --- |
| 消费纠纷/预付卡 | 12315（全国12315平台） |
| 政务、公共服务、租房纠纷 | 12345 |
| 劳动纠纷（欠薪、违法解除、社保） | 劳动人事争议仲裁委员会（免费）、劳动保障监察大队 |
| 诈骗（转账、刷单、假客服） | 110/反诈专线96110 |
| 法律咨询 | 12348公共法律服务热线 |
| 公积金12329｜人社12333｜医保12393（部分地区） | 电话咨询 |

维权三原则：先留证据再吵架；书面沟通优先（微信文字>电话，电话要录音）；按层级递进（协商→平台介入→行政投诉→诉讼/仲裁）。

取证的三条边界（很重要）：① 只限自身合法权益受到侵害时取证，不要顺手录制无关的谈话与场景；② 只限必要范围——能证明争议事实的部分即可，不进入他人私人空间、不拍摄与争议无关的第三人；③ 只向有权机关提交（法院、仲裁机构、行政机关、平台投诉通道），不得剪辑后公开发布到网络。把他人影像、录音发到网上，可能侵害肖像权、隐私权与个人信息权益，维权人反而变成侵权人；证据用完即清，不长期留存。

反向清单：这些“省钱”会让你更贵

- ×买临期食品吃到过期→肠胃炎的费用>省下的20元
- ×三年不体检→小病拖成大病
- ×住消防不合格的隔断房/群租房→火灾风险+随时被清退
- ×夏天为省电费不开空调→中暑、热射病
- ×不买百万医疗险→一场大病的自费部分吞掉几年积蓄
- ×每天通勤3小时→时间、健康、职业成长全部受损
- ×买“共享账号”→封号、信息泄露、被诈骗
- ×自己动手改水电燃气→事故成本无法承受判断标准：省钱的收益是确定的、有限的；风险的损失是不确定的、可能无限的。涉及安全、健康、法律的事项，不要省。
