这不是一本教你“节俭”的书。它只讲一件事：在一线城市，同样的收入，为什么有人每月能存下5000，有人月底归零。差别通常不在收入，而在七个决策——住哪、吃什么、怎么通勤、话费套餐、看不看病、买不买东西、知不知道政策。

<a id="s0-1"></a>

## 0.1 这本书写给谁

写给在北京、上海、广州、深圳工作，月收入6000~30000元，既不想过苦日子、也不想月底看余额发呆的普通人。尤其写给三类人：

- 刚来一线城市的第一年——你即将做出的租房、办卡、参保决策，会锁定未来两三年的成本；
- 工作三五年、收入涨了但存款没涨——大概率是固定支出被“生活方式膨胀”吃掉了；
- 准备离开或准备留下的人——离开前该提取的公积金、该领的补贴、该转的社保，都在第八章。

<a id="s0-2"></a>

## 0.2 三条原则

第一，省钱是降低“单位体验成本”，不是降低体验。判断标准是“每1元换到多少东西”。8000元的一居室与4500元的地铁末端一居室，多花的3500元买到的是每天40分钟通勤，即每月约20小时——这份时间值不值3500元，你必须算过，而不是想当然。

第二，固定支出优先于变动支出。房租、宽带、话费、会员订阅，这些“每月自动扣”的项目，一次优化、长期生效。而“今天不喝奶茶”省下的钱，往往在第三天的报复性消费里蒸发。

第三，能用政策解决的，不要用钱解决。公积金租房提取、医保门诊统筹、个税专项附加扣除、保障性租赁住房、职业技能提升补贴、以旧换新补贴——这些是城市发给你的钱，不知道就等于放弃。

<a id="s0-3"></a>

## 0.3 怎么读

- 只有30分钟：读第八章（制度性收入）和第十三章（防守），这两章基本不需要改变生活习惯，只靠“知道”就能拿回钱；
- 准备换房：读第一章，再读你所在城市的章（第九至十二章）；
- 想系统性降本：按第一至八章顺序读，每章末尾有“本节相关链接”，直接跳去办理；
- 每章末尾的小节：一节讲一件事，节末是该节要用到的官方入口，看完就能办。

<a id="s0-4"></a>

## 0.4 一句提醒

书里的金额是区间参考值，政策会变。涉及申领、报销、资格认定的，一律以官方最新公告为准——本书只负责告诉你“有这么个东西、大概什么水平、去哪里办”。凡是需要“打听”的信息，最好的来源永远不是攻略，而是这三个地方：本地政务App的办事指南、所在区主管部门的公众号、以及12345的一通电话。
