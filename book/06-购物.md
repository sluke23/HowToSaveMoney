一线城市里，常见的消费误区不是房子和车，而是“以为自己需要”。这一章解决两个问题：买之前怎么判断该不该买；确定要买时，怎么少花40%。

<a id="s6-1"></a>

## 6.1 一个公式决定“该不该买”

单次使用成本=（购买价−残值）÷预计使用次数

| 物品 | 价格 | 实际次数 | 单次成本 | 结论 |
| --- | --- | --- | --- | --- |
| 3000元健身年卡 | 3000 | 10次 | 300元 | 极贵 |
| 800元跑鞋 | 800 | 200次 | 4元 | 便宜 |
| 200元“便宜”外套（版型差、起球） | 200 | 5次 | 40元 | 比800元穿100次的外套贵5倍 |
| 500元二手空气炸锅 | 500 | 150次 | 3.3元 | 便宜 |

两条推论：1. 高频使用的值得买贵的（床垫、椅子、鞋、锅、手机）——按次摊销；2. 低频使用的只配租、借、买二手（电钻、行李箱、露营装备、正装、相机）。

租房时代的补充规则：搬家次数决定你的购物上限。每次搬家，非必需品都在消耗搬家和心理成本。“能不买就不买”在租房阶段是最有效的策略。

## 6.2 二手：一线城市最大的隐形折扣市场

人口流动快，“买错”和“搬家甩卖”的量极大，所以一线城市是二手市场最成熟的地方。

| 品类 | 二手价/新品价 | 平台 | 注意 |
| --- | --- | --- | --- |
| 家具（宜家、实木） | 20%~40% | 闲鱼 | 同城自提最便宜；拆装件要清点螺丝 |
| 家电 | 30%~50% | 闲鱼、转转 | 通电验机、查生产年份 |
| 书 | 20%~50% | 多抓鱼、孔夫子旧书网 | 教材、专业书性价比极高 |
| 数码 | 50%~70% | 闲鱼、官方翻新店 | 查序列号/保修、当面验机 |
| 健身器材 | 20%~40% | 闲鱼 | “办了卡不去”的人多，成色新 |
| 正装/礼服 | 20%~40% | 闲鱼、租赁平台 | 穿一次就租更划算 |

买二手四条铁律：1. 同城自提、当面验货，绝不见不到实物就转账；2. 走平台交易，不脱离平台私下转账；3. 电子类查三样：序列号可查保修、电池健康度、开机实测；4. 警惕“低价钓鱼”：低于市场价50%以上的，基本都是骗局（“先付定金”“物流代收”）。

卖二手也是省钱：一年清一次闲置，普通家庭能回收1000~3000元。挂闲鱼的技巧是——标题写品牌型号+尺寸，实拍多张，价格留10%议价空间。

## 6.3 三个“便宜但要看懂”的渠道

1688（源头批发）

- 优势：工厂直供，同类商品比零售平台低20%~50%；
- 门槛：部分商品有起订量；运费自理；
- 风险：无七天无理由、无售后，退货成本可能高于商品价值；
- 适合买：日用品（收纳、餐具、清洁工具）、办公耗材、饰品、宠物用品、包装材料。
- [拼多多](https://www.pinduoduo.com)
- 百亿补贴区常有品牌数码／家电的阶段性低价，部分商品标注“正品险”；是否真便宜，建议先用比价工具查6个月历史价再下单；
- 农产品（水果、坚果、米面）价格接近产地价；

临期折扣店

- 零食、饮料、粮油、日化常见3~5折；
- 关键看保质期还剩多久——剩1个月的牛奶，只有能在一个月内喝完才划算；
- 适合买：能快速消耗的（饮料、零食、纸品、洗衣液）。

奥特莱斯与断码店：运动鞋服、内衣、基础款，换季断码常有3~5折。买基础款最划算，因为它们不过季。仓储会员店（山姆/Costco）：单价低但总价高，适合3人以上家庭或合租拼单。一个人住，会员费大概率不划算。

## 6.4 大促：多数人在大促里花得更多

三条铁律：1. 清单先行：大促前两周列出要买的，写清“型号+心理价位”。不在清单上的一律不买，哪怕“便宜了800”。2. 查历史价格：用比价工具看过去6个月的价格曲线。很多“大促价”是先涨后降。3. 只算实付：定金膨胀、跨店满减、品类券叠加后的最终实付才是价格。算不清就不买。

“满300减50”的陷阱：为凑单多买的250元东西是净支出，不是“省了50”。凑单前问自己：“如果它不打折，我会买吗？”价保：多数平台有“7~30天价保”，买完后可以主动申请差价退还。下单后截个图，一周后再看一眼价格，这是很多人白丢的钱。

| 品类 | 一年中的低价窗口 |
| --- | --- |
| 家电、数码 | 618、双11、国补期、新品发布后的上一代清仓 |
| 服装 | 换季（3—4月、9—10月）、双11 |
| 家具 | 双11、宜家年末清仓、毕业季与年底的二手市场 |
| 生鲜 | 应季+社区团购 |

## 6.5 政策补贴与“隐形折扣”

以旧换新（国补）近年持续推进消费品以旧换新：家电（冰箱、洗衣机、空调、电视、电脑等）、数码（手机、平板、手表）、汽车、家装厨卫等，补贴比例常见15%~20%，单件有上限（家电常见最高2000元、数码常见最高500元，以当年政策为准）。路径：在京东/天猫/苏宁/线下门店搜“以旧换新”“国补”专区→确认商品在目录内且所在城市参与→旧机可折价→保留发票与补贴凭证。补贴名额分批投放，先到先得。其他常被忽略的折扣：

| 项目 | 说明 |
| --- | --- |
| 信用卡权益 | 返现、满减、机场贵宾厅、免费体检、洗牙、电影票；年费卡要算清“权益是否值回年费” |
| 信用卡积分 | 可换里程、话费、超市券；注意有效期，别囤到过期 |
| 企业内购 | 大厂/外企常有品牌内购、员工折扣平台，折扣常5~8折 |
| 银行App商城 | 分期免息+满减，常比电商便宜 |
| 运营商权益 | 话费积分换视频会员、流量包 |
| 工会会员服务卡 | 部分城市的工会卡有指定商户折扣、公园/影院优惠（见第九至十二章） |
| 以租代买 | 礼服、相机、露营装备、婴儿车、空气净化器，短期用租比买便宜80% |
| 共享工具 | 电钻、梯子、吸尘器，社区/朋友间借用，或按次租 |

## 6.6 会员卡：把年费花在“本来就要花”的地方

除了一次性的买东西，一线城市还有一类支出是“按月、按年悄悄扣”的：视频、音乐、外卖、网盘、电商、仓储店、出行……一张张会员卡加起来，一年轻松过千。它们本身不坏，坏的是开了不用、续了不取消。判断标准只有一条：这笔年费能不能被你本来就要花的钱覆盖。能，它就是一张折扣券；不能，它就是一笔订阅税。

需要说明的是：下面只是举几个常见会员的例子，帮你认识这类卡一般会附赠什么、以及怎么用才不浪费。各家权益调整频繁，门槛和价格还因人而异，这里不做优劣比较，也不构成任何购买建议——具体以你打开 App 时看到的当期页面为准。

付费会员通常附赠什么付费会员卖的往往不只是“折扣”，而是一捆打包的权益。把它们的类型认清，比记住某一家App的规则更有用：

| 权益类型 | 常见形式 | 通常出现在哪类会员里 |
| --- | --- | --- |
| 视听内容 | 视频、音乐、听书会员（打包或二选一） | 电商会员常附赠；视频、音乐、播客平台自身也卖年卡 |
| 外卖 | 到家红包、免配送费券、吃货卡、到店折扣 | 外卖平台与本地生活平台 |
| 生活服务 | 保洁、洗鞋洗衣、洗车、寄件、在线问诊、洁牙等，多用积分或权益点兑换 | 部分电商会员的“生活服务包” |
| 云盘与工具 | 网盘空间和会员、文档与图片工具 | 网盘类、工具类App自身的会员 |
| 出行权益 | 酒店会籍、打车券、机票券、贵宾厅 | 旅行平台会员，也常见于银行与电商的联合权益 |
| 购物折扣 | 全站折扣、大促消费券、退货包运费与券 | 电商会员 |
| 仓储会员 | 自有品牌商品，以及洗车、验光、轮胎等门店服务 | 仓储式会员店 |
| 知识与运动 | 电子书、课程、健身内容与场馆折扣 | 阅读类、学习类、健身类App |

看这张表能发现一件事：很多权益是重叠的——视频、音乐、网盘这几项，电商会员、运营商权益、银行权益里都可能出现。重复开通同一项，是最常见的一种浪费。几个常见会员的例子（仅作介绍，不作比较）

- 电商会员（如京东 PLUS、淘宝88VIP）：除了免运费、返积分，通常还附带一捆外部权益——视听会员、外卖券包、网盘会员、出行权益，以及可以用积分兑换的保洁、洗鞋、寄件、洗车、在线问诊等生活服务。年费各有分档（有的与消费活跃度挂钩），大促期间开通价通常低于平时；其中不少权益需要手动领取，不领视同放弃；
- 仓储会员店（如山姆、Costco 等）：年费制，权益主要来自自有商品和门店服务（洗车、验光、轮胎、烘焙等），适合家庭批量采购，不适合一个人少量买；
- 视听与内容会员（视频、音乐、听书、网盘）：年卡本身就是权益，经常与电商、运营商、银行的权益互绑，是重叠率最高的一类，开之前先看看自己有没有已经“白拿”的渠道；
- 外卖与本地生活会员：本质是一个券包（红包、免配送费、到店折扣），用得频繁才成立，点得少就是净支出；
- 旅行平台会员：酒店会籍、里程加速、贵宾厅、退改权益等，对一年出行次数稳定的人才有意义；
- 阅读、健身、工具类会员：通常按月开更灵活，不建议默认自动续年——真用到一整年，再改年卡也不迟。怎么用才不亏（通用四条）1. 先算再用：把去年在这家平台的实付金额拉出来，用“年费 ÷ 折扣率”估算自己的回本最低消费额，达不到就不开；2. 开通当天把附赠权益全部激活——视听、网盘、券包大多要手动领，并在日历里标好到期日；3. 权益都有期限：券包、积分、兑换额度一般按月或按年清零，按季度安排着用，别等到过期；4. 到期前30天做一次体检：这一年真的用回本了吗？没有就立刻关掉自动续费。
