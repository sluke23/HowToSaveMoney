省钱是入口，不是出口。省下来的钱如果躺在活期里被通货膨胀慢慢吃掉，前面十三章的功夫就白做了。这一章不推荐任何具体产品，只讲“次序”，收益率再高也补不回流动性的缺口。顺带提醒：这一章里最确定的收益不是投资回报，而是国家给的税收优惠和费用减免。

<a id="s17-1"></a>

## 17.1 配置次序：不可跳步

第十七章不谈“怎么赚”，只谈“怎么不亏、不被手续费吃掉”。顺序必须是：应急金 → 保险 → 税优账户 → 长期投资（详见8.7的账户结构）。1. 应急金：3—6个月开支，放货币基金或活期，雷打不动。这笔钱的作用是让你在一线城市敢辞职、敢生病、敢拒绝一份烂工作。2. 保险：医保打底 → 百万医疗险（保费随年龄与保障范围差异较大）→ 意外险 → 有房贷、有孩子以后加定期寿险。保费按家庭情况量力配置，没有统一比例——先保额后保费，别为买保险把现金流压死。3. 个人养老金账户：每年缴存上限12000元，缴存即可在个税中扣除，适用税率越高越划算（10% 税率档约省1200元/年，20% 档约2400元/年）。4. 长期钱：宽基指数基金定投 + 国债 / 存款。存款认准存款保险（同一家银行50万元以内）；不择时、不加杠杆、不追热点。

<a id="s17-2"></a>

## 17.2 税优账户：一年几千元的确定性收益

- 个人养老金：在银行开立账户后，每年缴存上限12000元，缴存金额在综合所得中据实扣除；账户内可买储蓄存款、商业养老保险、公募基金等，投资环节税费暂免。
- 住房贷款利息专项附加扣除：首套住房贷款利息每月1000元定额扣除，最长240个月，一生只能享受一次（见8.1）。
- 住房公积金本身就是税优：缴存部分不计入应纳税所得额，且租房、装修、购房都能提取（见8.3）。

<a id="s17-3"></a>

## 17.3 国家认可的低风险理财

- 储蓄存款：受《存款保险条例》保障，同一家银行50万元以内本息全额赔付；
- 储蓄国债：财政部发行，3年/5年期，以国家信用为支撑，信用风险极低，手机银行可购；
- 个人养老金账户内产品：储蓄存款、国债等，叠加税收优惠（见17.2）；
- 货币基金：低波动现金管理工具，流动性好，但不属于保本产品。

风险提示：以上为公开信息整理，不构成投资建议；任何产品均不承诺保本，“保本高收益”一律警惕。

<a id="s17-4"></a>

## 17.4 红线：守不住的部分，前面都白省

承诺“保本高收益”的一律违规或诈骗（呼应13.5）；“内部消息”“稳赚群”是杀猪盘的标准剧本；投资前在证监会、国家金融监督管理总局官网查机构与产品资质，不确定就不投。理财目标不是暴富，而是让省下来的钱尽量不被通胀侵蚀、别亏回去。
