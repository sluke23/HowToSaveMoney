# 使用维权分诊台 Skill

**我这事该找谁、第一步做什么、证据留到什么程度。**

`dispute-router` 把租房押金、消费退款、预付余额、欠薪、异常扣费和疑似诈骗等经历，整理为主渠道、第一步、证据缺口和后续行动条件。作者：毛毛&luke。

入口：[skills/dispute-router/SKILL.md](../skills/dispute-router/SKILL.md)。内置指南相关摘录、渠道判断方法和可复制的材料模板，可独立安装。资料可离线查询；现行管辖、期限和提交要求需核对适用官方资料。

## 安装

先下载或克隆仓库，在仓库根目录运行。**复制整个文件夹，不能只复制 SKILL.md**；目标目录已有同名 Skill 时，先检查或备份自己的修改。

### Claude Code

```bash
mkdir -p "$HOME/.claude/skills"
cp -R skills/dispute-router "$HOME/.claude/skills/"
```

打开新会话，用 `/dispute-router` 调用。

### Codex

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/dispute-router "${CODEX_HOME:-$HOME/.codex}/skills/"
```

打开新会话，用 `$dispute-router` 调用。

### WorkBuddy

```bash
mkdir -p "$HOME/.workbuddy/skills"
cp -R skills/dispute-router "$HOME/.workbuddy/skills/"
```

重新打开会话，确认当前版本扫描目录和 Skill 列表，再提出“使用 dispute-router，帮我……”的问题。发现与加载方式以实际版本为准。

## 可以这样问

**私人房东扣押金：先分清合同与行政渠道。**

```text
使用 $dispute-router。我在上海向私人房东租房，退租后押金 3000 元没退。
有合同、转账和入住视频，退租时微信确认已交钥匙，但没签验收单。
房东说墙面脏，尚未提供修理明细；我想要回合理扣费后的余额，还没书面催过。
该找谁？今天先发什么？现有证据够做什么，还缺哪几项？
```

应先对照租约、交接情况与扣费理由，整理请求金额和催告草稿；说明私人房东纠纷为何不能直接套用 12315。若已明确拒绝或失联，则结合争议条款核对调解或民事程序，不要求把所有热线先打一遍。

**健身房停业：查清谁收钱、余额怎么算。**

```text
使用 $dispute-router。北京一家健身房关门一周，充值合同写的是 A 公司，
付款给 B 公司，品牌客服说是加盟店。我实际付 4000 元、赠 1000 元，
消费记录显示用了 1200 元，但没写先扣本金还是赠额。
我有合同、账单、余额截图和门店公告。怎么找处理渠道，先补什么证据？
```

应把合同主体、收款方和服务方分别列清，核对退款约定及已消费金额，不能直接拿截图余额当全部现金债权，也不因关门或加盟就认定诈骗、总部必赔。再按当地行业与受理规则选主渠道，留好停业与退款回复材料。

**没签合同的欠薪：先看实际用工关系。**

```text
使用 $dispute-router。我在深圳工作，没签劳动合同，连续上班三个月，
每天由主管排班、打卡，有工作群和前两个月公司账户转来的工资。
最后一个月 8000 元未付，已离职，老板明确说不付。
请判断先核对监察还是劳动仲裁，列第一步与证据缺口，不要让我重发无效催告。
```

应先查实际管理、报酬、离职时间和主体，不能因没合同就排除劳动关系。按请求区分劳动监察与劳动仲裁，核对管辖和时效；单位掌握的材料另列线索和依法请求提供的办法，不要求用户冒险获取。

**正在发生的疑似诈骗：不等整理完材料。**

```text
使用 $dispute-router。有客服让我开屏幕共享退订会员，我刚转了 2000 元，
他又让我交一笔解冻费，通话还没结束。我现在先做什么，哪些记录要保留？
```

应先提示停止新增付款、关闭屏幕共享，用独立可信设备从官方渠道联系银行/支付机构，并向 110 或当地公安机关报案；保留交易号、时间、对方账号与接触记录。不能先让用户凑齐材料再报警，也不能保证止付或退款结果。

Claude Code 将上述 `$dispute-router` 换成 `/dispute-router`；WorkBuddy 可写“使用 dispute-router”。示例是使用情景，不是已处理个案或结果承诺。

## 会拿到什么

一张简短分诊单，说明初步关系与主渠道、今天第一步、够用的证据及缺口、保留原件的阶段、下一步触发条件。需要沟通时附事实说明草稿；有法定期限时单独核对，建议回复日期不冒充法定期限。

证据围绕“与谁约定、付了多少、怎么履行、哪里有争议、提出过什么请求”整理，模板见[证据与行动模板](../skills/dispute-router/references/evidence-and-actions.md)。客服点结案、首次提交或拿到裁判都不自动代表可以删除原件，要考虑履行、后续救济和执行等阶段。

Skill 不会自动发消息、拨号、提交投诉或立案，也不需要接收完整身份证、账号密码和验证码。提供截图或合同片段前遮盖无关个人信息；正式办理所需身份资料由本人通过核实过的渠道提交。

渠道边界见[分诊方法](../skills/dispute-router/references/routes.md)，已读取的官方依据与尚待核实范围见[官方核对记录](../skills/dispute-router/references/official-verification.md)。仓库结构检查不保证个案受理、证据认定或模型回答质量。

## 维护与许可

```bash
python3 tools/build_skill.py
python3 tools/build_skill.py --check
python3 tools/check.py
python3 -m unittest discover -s tools/tests
```

不要直接修改 `skills/dispute-router/references/guide/`。入口、三份方法文件与使用示例由人工维护；程序变化时更新具体官方核对记录。安装副本不会自动更新，更新仓库后需重新复制整个目录。
