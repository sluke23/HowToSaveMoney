# 使用成本结构说明书写作器 Skill

**把本书体例抽象成“给任意主题写同款说明书”的纪律。**

`cost-guide-writer` 提炼《一线城市省钱指南》的写作方法：围绕读者决定组织内容，把金钱、时间、资金占用和风险说清，比较同等需求下的方案，用条件明确的算例支持结论，再给读者能做的第一步。作者：毛毛&luke。

入口：[skills/cost-guide-writer/SKILL.md](../skills/cost-guide-writer/SKILL.md)。内置体例样本、写作与核查方法，以及家庭打印的跨主题完整示例，可独立安装；不要求安装其他 Skill。新主题的价格、政策、技术限制和效果等，需要该主题自己的适用依据。

## 安装

先下载或克隆本仓库，在仓库根目录运行。**复制整个文件夹，不能只复制 SKILL.md**；已有同名目录时先检查或备份自己的修改。

### Claude Code

```bash
mkdir -p "$HOME/.claude/skills"
cp -R skills/cost-guide-writer "$HOME/.claude/skills/"
```

打开新会话，用 `/cost-guide-writer` 调用。

### Codex

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/cost-guide-writer "${CODEX_HOME:-$HOME/.codex}/skills/"
```

打开新会话，用 `$cost-guide-writer` 调用。

### WorkBuddy

```bash
mkdir -p "$HOME/.workbuddy/skills"
cp -R skills/cost-guide-writer "$HOME/.workbuddy/skills/"
```

重新打开会话，确认当前版本扫描目录和 Skill 列表，再提出“使用 cost-guide-writer，帮我……”的问题。发现与加载方式以实际版本为准。

## 可以这样问

**把一个新主题写成正文。**

```text
使用 $cost-guide-writer，写一篇给低频家庭用户的“家里要不要买打印机”说明书，
约 1500 字，重点比较未来三年的普通 A4 黑白打印。两种方案都满足质量要求。
全部用以下假设，不要伪造市场报价：新机 900 元，三年无额外维修、残值为零；
自印每页 0.10 元已含纸、电和耗材，外部每页 0.50 元，无起印费。
比较每年 300 页和 1000 页，另看设备额外维修 200 元时的变化。
时间、便利与隐私单列，不硬折成工资；给复算、结论反转条件和第一步。
我要完整正文，不只要提纲。
```

这些假设下，三年 900 页时外部打印少付 540 元；三年 3000 页时购机少付 300 元。无额外维修的等成本点为 2250 页，从 2251 页起购机才严格更省；额外维修 200 元时等成本点为 2750 页。成稿应解释这些条件，并让读者先核对真实用量、报价与维护边界。完整示范见 [家庭打印示例](../skills/cost-guide-writer/references/worked-example.md)。

**为另一个领域搭框架。**

```text
使用 $cost-guide-writer，为“独立开发者的小网站怎么选部署方案”设计说明书目录。
读者没有专职运维，关注一年成本、维护时间、备份恢复和迁移。
这次只要目录、每章要回答的决定、需要查的资料和拟做的算例。
没有访问到产品文档时，不要填写当前价格、免费额度或某个服务必有的功能。
不要照搬租房和医保章节，也不要直接创建项目代码。
```

目录应围绕真实服务需求、用量、运维与迁移等决定组织；价格、功能、版本和费用边界作为研究任务。不能只按品牌列清单，或把“任意主题”理解成无需领域资料也能给出可靠产品结论。

**给旧稿补条件与复算。**

```text
使用 $cost-guide-writer，改写下面一段，使读者能判断值不值，不要只换形容词：
“年费 100 元的会员全场 95 折，人人回本，半小时一年省几千，直接买。”
目前只有这些假设：参与折扣的原定消费打 95 折，年费 100 元，无其他费用；
参与范围和实际报价还没查。请给修订正文、计算边界和需要补的资料，
不要冒称这是某个现实商户的权益。
```

应说明只有符合折扣的原定消费才计入，`100÷5%＝2000 元`是等成本点，不能用 95% 做分母，也不能保证每个人回本。修订后要有核对参与范围、真实消费与年费条件的具体动作，未查资料保留缺口。

**资料不足，完成有边界的稿件。**

```text
使用 $cost-guide-writer，写一篇“搬家该自己搬还是找服务”的短说明书。
读者是东西不多、无大型家具的租客；先讲比较方法，具体价格用明示假设，
当前城市报价、服务赔付与合同条款都没核实。
把搬运、交通、打包、体力和可用时间纳入，给一组可复算的假设例子，
另列询价要问什么、完成比较需要哪些凭据。不要写成亲测经历或保证省钱。
```

这时仍可交付方法正文和明示的假设算例；现实价格、服务能力与合同条件写成核对任务。不能凭一个商户主页就声称查清所有收费，也不应因无实价而只交“之后可以调研”的计划。

Claude Code 将 `$cost-guide-writer` 换成 `/cost-guide-writer`；WorkBuddy 可写“使用 cost-guide-writer”。上述价格和计算均是演示，不是当期报价或真实使用结果。

## 写作纪律落在哪些地方

| 要求 | 读者应在稿件中看到什么 |
| --- | --- |
| 围绕决定 | 谁在什么条件下选什么，而不是知识点或品牌的堆砌 |
| 同口径比较 | 相同需求、期间、用量与质量底线；关联费用、退出成本和资金占用有交代 |
| 可复算 | 输入、公式、单位、假设与结果一致，并说明哪项变化会改变结论 |
| 可核对 | 事实、用户信息、假设与建议分清，关键结论有对应依据和适用范围 |
| 可执行 | 第一步看什么、问谁、取得什么材料；怎样判断完成、何时复核 |
| 少口号 | 用条件与证据替代“铁律、人人必省、闭眼入”等断言，不训诫读者 |

具体方法见 [写作体例](../skills/cost-guide-writer/references/writing-method.md) 和 [成本与依据纪律](../skills/cost-guide-writer/references/cost-and-evidence.md)。对健康、法律、金融等主题，成本比较不能替代必要的专业判断；无法量化的因素可以作为约束或取舍，不强行拼成一个总分。

短文默认直接交付正文，按需附核查记录；长稿才逐步增加目录、工具表和维护文件。Skill 不会因写稿就自动建仓库、做网站或向平台发布。

```bash
python3 tools/build_skill.py
python3 tools/build_skill.py --check
python3 tools/check.py
python3 -m unittest discover -s tools/tests
```

Skill 入口和三份方法/示例文件由人工维护。安装副本不会自动更新，更新仓库后需重新复制整个目录。自动检查验证结构、链接与来源同步，不能保证新主题的事实已核实或所有模型都能稳定遵循写作要求。
